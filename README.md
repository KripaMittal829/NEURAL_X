# NEURAL_X
NEURAL_X is a futuristic cyberpunk-inspired landing page prototype for a fictional human-augmentation company specializing in AI-powered robotic organs and cybernetic enhancements.

Designed with a premium Neon Dark UI aesthetic, the project showcases advanced synthetic technologies including neural hearts, quantum vision systems, bio-mechanical limbs, AI spine matrices, and intelligent memory implants.

✨ Features

- Cyberpunk / Neon Dark themed responsive UI
- Animated futuristic grid background & glowing effects
- Premium glassmorphism navbar and modal design
- Sign Up / Sign In authentication modal
- Password validation + visibility toggle
- Interactive 3D flip product cards
- Smooth animations & hover transitions
- Fully responsive across mobile, tablet, and desktop devices
- Modern HTML, CSS, and Vanilla JavaScript implementation

🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Design (Flexbox + Grid)
- Font Awesome Icons
- Google Fonts
